Mi vida y mi trabajo

Antes de escribir código defino los requerimientos y las reglas de negocio. En PrestaFácil, por ejemplo, documenté cómo se calculan las cuotas y la mora, y luego escribí pruebas que verifican que la API y la base de datos den exactamente los mismos montos.

Trabajo con arquitectura en capas, pruebas unitarias, control de versiones con Git e integración continua con GitHub Actions. Busco mis primeras prácticas o empleo como desarrolladora backend o full stack.
